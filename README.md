# DeskFlow

Organizador de escritorio (Electron) — lanzador por grupos, carpetas vigiladas, tema claro sistemasymas.

## Desarrollo

```bash
npm install
npm run dev          # Ctrl+Shift+D en la app
npm run typecheck
```
